Epopee: E14 | Type: code | Dependances: E14-06 | Taille estimee: ~140 lignes

## Contexte
Prouve que le serveur est CONNECTE au vrai crate : un client WebSocket pilote un programme et on compare avec une execution directe du crate.

## Specification
`crates/puce-z80-web/tests/e2e.rs` : lance le serveur sur un port libre (thread), se connecte avec `tungstenite`, `load` d'un petit programme CP/M ecrit en octets (ex. `LD A,5; LD B,3; ADD A,B; LD E,A; ... JMP 0`), envoie `step{n:3}` et verifie : `regs.af` et `regs.bc` du JSON == valeurs d'un `Cpu` execute DIRECTEMENT dans le test avec le meme programme (`CpmMachine`) ; verifie aussi `dis[0].text` == `disassemble(...)`; puis `run` jusqu'a `done` et compare `n`, `t` et la console.


## Tests
Tous les tests sont prefixes par `e14_07_`.

- `e14_07_regs_equal_direct_cpu` : regs du JSON == regs du Cpu direct apres 3 instructions
- `e14_07_dis_from_crate` : dis[0].text == disassemble
- `e14_07_run_to_done` : n, t et console identiques a l'execution directe
- `e14_07_alu_from_crate` : alu.op/r issus du crate apres ADD
