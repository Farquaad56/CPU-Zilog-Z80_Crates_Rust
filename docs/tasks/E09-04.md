## Specification
`start_nmi()` : `eng.irq = Nmi`; plan statique `NMI_PLAN = [F5 (variante sans PC+, sans decodage), W3:-SP<H, W3:-SP<L, X0]` (ajoute si besoin les variantes `Kind`/champ necessaires : un M1 de 5 T dont l'octet lu est IGNORE, PC non incremente, R incremente, refresh normal) ; TMP = PC (adresse de retour ; si `halted` : PC+1 et `halted=false`). Au hook final : `IFF2 = IFF1; IFF1 = false; PC = 0x0066; WZ = 0x0066`. Total 11 T. `RETN` (ED 45, E07-04) restaure IFF1.

## 2. Sequences

| Evenement | Cycles | T | Effet |
|---|---|---|---|
| NMI | `F5` (M1 sans PC++ ni RD/MREQ effectif, RFSH) + `W3` + `W3` | 11 | IFF2=IFF1, IFF1=0, push PC, PC=0x0066, WZ=0x0066 |
| INT mode 0 | M1 d'acquittement (IORQ|M1, 2 TW automatiques) puis l'instruction lue sur le bus (typiquement RST n) | 13 pour RST | IFF1=IFF2=0 |
| INT mode 1 | `IA` (M1 ack 7T: 4+2 TW+1?) + `W3` + `W3` | 13 | push PC, PC=0x0038 |
| INT mode 2 | `IA` 7T + `W3` + `W3` + `R3` + `R3` | 19 | vecteur = (I<<8)|(octet du bus & 0xFE); PC = mot lu |
| HALT | NOPs M1 jusqu'a INT/NMI | 4 par NOP | a l'acceptation, PC pointe sur l'instruction apres HALT |
| RESET | 3 T min | - | PC=0, I=0, R=0, IFF1=IFF2=0, IM=0; AF=SP=0xFFFF (NMOS: autres registres inchanges) |

Le cycle d'acquittement INT a M1=1 ET IORQ=1 (et pas MREQ). L'octet lu est fourni par `Bus::int_ack()` (ou D0..D7 de `pins_in`).

## Tests
Tous les tests sont prefixes par `e09_04_`.

- `e09_04_nmi_11t` : NMI apres un NOP: l'interruption dure 11 T
- `e09_04_nmi_pushes_pc` : PC de retour poussee: octet haut a SP+1
- `e09_04_nmi_vector` : PC=0x0066 et WZ=0x0066
- `e09_04_nmi_iff` : IFF2=ancien IFF1, IFF1=0
- `e09_04_nmi_wakes_halt` : NMI pendant HALT: pousse PC+1
- `e09_04_nmi_priority` : NMI et INT simultanes: NMI d'abord
- `e09_04_retn_restores` : RETN remet IFF1=IFF2
