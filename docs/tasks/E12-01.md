# E12-01 - Feature inspect: journal de la derniere operation ALU
Epopee: E12 | Type: code | Dependances: E11-05 | Taille estimee: ~110 lignes

## Contexte
Le frontend affiche l'operation ALU en cours (op, operandes, resultat, drapeaux). Elle doit venir du crate, sous la feature `inspect` (zero cout par defaut, comportement identique).

## Specification
Dans `probe.rs` (`#[cfg(feature = "inspect")] pub mod probe;`) : `pub struct AluRecord { pub op: u8 /*0..7 alu8, 8 inc,9 dec, 16.. rot, 32 add16, 33 adc16, 34 sbc16, 40 daa, 41 neg, 42 cpl*/, pub w: u8 /*8 ou 16*/, pub a: u16, pub b: u16, pub c: u8, pub r: u16, pub f_in: u8, pub f_out: u8 }` et `Cpu::last_alu(&self) -> Option<AluRecord>` (champ `#[cfg(feature = "inspect")] pub(crate) last_alu` dans Cpu).
`sem/**` enregistre l'operation via une fonction `probe::alu(cpu, record)` qui est un `#[inline(always)]` vide hors feature. Branche-la dans les appels a `alu8`, `inc8/dec8`, `rot`, `add16/adc16/sbc16`, `daa`, `neg`.

## 2. Serveur -> client

`{"type":"roms","roms":[{"name","size","total_tests"}]}`

`{"type":"state", ...}` au plus 30 fois/s pendant `run`, et immediatement apres chaque commande:

```
status: "idle"|"running"|"halted"|"done"|"bp"      n, t (entiers 64 bits), ips, mhz (nombres), tlast
regs: {af,bc,de,hl,af2,bc2,de2,hl2,ix,iy,sp,pc,i,r,wz (entiers), iff1,iff2,im}
bus:  {addr, data, kind: 0 fetch|1 read|2 write|3 io-read|4 io-write, pins: "0x..." (u64 de Pins, 37 bits)}
alu:  {op (nom: ADD, ADC, SUB, SBC, AND, XOR, OR, CP, INC, DEC, ADD16, ADC16, SBC16, DAA, NEG, CPL, ...), w (8|16), a, b, c, r, f_in}                       (feature inspect: derniere operation ALU)
dis:  [{addr, bytes:[...], text, len, pre ('' | CB | ED | DD | FD | DDCB | FDCB), op}]  dis_rows lignes a partir de PC (desassembleur du crate)
trace:[{pc, text}]  plus recentes en premier      stack:[{addr, word}]
mem:  {base, hex: "<512 caracteres hex>"}          wlog: [adresses ecrites recemment]
console_delta: "texte ajoute depuis le dernier state"    tests: {ok, err, total}
bps: [adresses]   rom: {name, size, kind: "cpm"|"raw"}
```

Regles: aucune valeur n'est calculee par la page (sauf mise en forme). Les mnemoniques viennent du crate (`disasm`). La page tolere des champs absents.

## Tests
Tous les tests sont prefixes par `e12_01_`.

- `e12_01_add_recorded` : ADD A,B: last_alu() donne op 0, a, b, r, f_out
- `e12_01_none_initially` : last_alu() None apres new
- `e12_01_inc_recorded` : INC B enregistre op 8
- `e12_01_add16_recorded` : ADD HL,DE w=16
- `e12_01_behavior_unchanged` : memes resultats avec et sans la feature (diff E05-16 passe avec --features inspect)
