# E09-05 - INT modes 1 et 2 (cycle d'acquittement)
Epopee: E09 | Type: code | Dependances: E09-04 | Taille estimee: ~140 lignes

## Contexte
Interruption masquable. Le cycle d'acquittement est un M1 avec IORQ (pas MREQ) de 7 T ; l'octet presente sur le bus de donnees est fourni par l'hote (`Bus::int_ack()` ou D0..D7 de `pins_in`).

## Specification
`start_int()` selon `regs.im` :
- IM 1 : plan `[IA7, W3:-SP<H, W3:-SP<L, X0]` -> 13 T ; X0 : IFF1=IFF2=false, PC=0x0038, WZ=0x38.
- IM 2 : plan `[IA7, W3:-SP<H, W3:-SP<L, R3:NN>Z, R3:NN+1>W, X0]` -> 19 T ; le vecteur est `(I<<8) | (octet_ack & 0xFE)` (place dans WZ avant les lectures, le plan lit un mot en memoire a cette adresse) ; X0 : PC = mot lu (WZ), IFF1=IFF2=false.
- `IA7` = jeton d'acquittement de 7 T qui utilise `mcycle::int_ack_pins` ; l'octet de bus est latche au dernier T d'attente (UNKNOWN - to confirm t exact : calage en E13-10 et E13-13) dans `eng.latched`. PC n'est PAS incremente. Si `halted` : PC+1 pousse, `halted=false`.
Le `Bus::int_ack()` est appele par `step()` quand `pins_out.is_int_ack()` (adapte E03-12 si necessaire).

## 2. Sequences

| Evenement | Cycles | T | Effet |
|---|---|---|---|
| NMI | `F5` (M1 sans PC++ ni RD/MREQ effectif, RFSH) + `W3` + `W3` | 11 | IFF2=IFF1, IFF1=0, push PC, PC=0x0066, WZ=0x0066 |
| INT mode 0 | M1 d'acquittement (IORQ|M1, 2 TW automatiques) puis l'instruction lue sur le bus (typiquement RST n) | 13 pour RST | IFF1=IFF2=0 |
| INT mode 1 | `IA` (M1 ack 7T: 4+2 TW+1?) + `W3` + `W3` | 13 | push PC, PC=0x0038 |
| INT mode 2 | `IA` 7T + `W3` + `W3` + `R3` + `R3` | 19 | vecteur = (I<<8)|(octet du bus & 0xFE); PC = mot lu |
| HALT | NOPs M1 jusqu'a INT/NMI | 4 par NOP | a l'acceptation, PC pointe sur l'instruction apres HALT |
| RESET | 3 T min | - | PC=0, I=0, R=0, IFF1=IFF2=0, IM=0; AF=SP=0xFFFF (NMOS: autres registres inchanges) |

Le cycle d'acquittement INT a M1=1 ET IORQ=1 (et pas MREQ). L'octet lu est fourni par `Bus::int_ack()` (ou D0..D7 de `pins_in`).

## 3. RETI / RETN / daisy chain

`RETI` (ED 4D) doit etre **observable** par les peripheriques en chaine (Z80 PIO/CTC/SIO) car ils decodent la sequence ED 4D sur le bus: le moteur ne triche pas, il execute les deux M1 normalement. `RETN` (ED 45): IFF1=IFF2 apres le pop.
