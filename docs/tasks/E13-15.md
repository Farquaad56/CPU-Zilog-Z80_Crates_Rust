## Contexte
z80test (z80doc, z80docflags, z80flags, z80full, z80ccf, z80memptr) est la suite la plus severe sur les drapeaux non documentes et MEMPTR. Elle tourne sur un ZX Spectrum (fichiers .tap/.z80) et affiche ses resultats a l'ecran.

## Specification
Clone `https://github.com/raxoft/z80test` (verifie l'URL) dans `tests/roms/z80test/`. Ecris `docs/specs/35_Z80TEST.md` : fichiers disponibles et formats (.tap, .z80, .sna, sources .asm), comment chaque test s'execute (point d'entree, ROM requise), COMMENT il rapporte le resultat (texte a l'ecran via RST 10h ? code de sortie ?), le texte exact de reussite ('Passed' etc.), les adresses ROM a intercepter pour un chargement rapide de bande (LD-BYTES 0556h) et pour capturer la sortie (RST 10h / PRINT-A), et les prerequis (ROM 48K fournie par l'utilisateur: `tests/roms/zx48.rom`). Pas de code Rust.
