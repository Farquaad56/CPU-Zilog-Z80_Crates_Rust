# E03-05 - Resolution des adresses (Addr)
Epopee: E03 | Type: code | Dependances: E03-04 | Taille estimee: ~120 lignes

## Contexte
Convertit un `Addr` du plan en adresse de bus avec ses effets de bord sur les registres (PC+, SP+, -SP, WZ...).

## Specification
Dans `engine/addr.rs` (`pub mod addr;`): `pub(crate) fn resolve(cpu: &mut Cpu, a: Addr, port: bool) -> u16` appelee UNE fois au tick t0 d'un jeton de bus:
- PcInc: renvoie PC puis PC += 1 (wrapping). Sp: SP. SpInc: SP puis SP += 1. SpPlus1: SP+1. DecSp: SP -= 1 puis renvoie SP. Hl, Bc, De: valeurs. Nn: WZ. NnPlus1: WZ+1 (wrapping).
- Xy: `base = IX ou IY selon eng.prefix`; adresse = base + signed(eng.disp); stocke dans `eng.xy_addr` ET dans `regs.wz`. 
- An (port=true): `(A << 8) | TMP.L`. Bc (port=true): BC. (Pour `port=false` l'adresse `Bc` est la paire memoire BC.)
- None: renvoie `eng.xy_addr` ou 0 (non utilise).
Tous les calculs 16 bits wrapping.

## 5. Adresses (`Addr`)

`PcInc`: adresse = PC puis PC += 1 (l'incrementation a lieu au tick t0 de ce cycle, apres emission de l'adresse). `Sp`: SP. `SpInc`: SP puis SP+=1. `SpPlus1`: SP+1 (SP inchange). `DecSp`: SP-=1 puis adresse SP (le decrement a lieu au tick t0 AVANT emission). `Hl/Bc/De`: registres (jamais IX/IY: l'indexation passe par `Xy`). `Nn`: WZ. `NnPlus1`: WZ+1 (et WZ n'est pas modifie). `Xy`: IX/IY + signed(disp), memorise dans `xy_addr` et dans WZ au premier usage (jeton `R3:PC+>D` termine). `An`: port: A15..A8 = A, A7..A0 = TMP.L (octet n lu); `Bc` en tant qu'adresse de port: BC complet (jetons `N4:BC` `O4:BC`).
<!-- end -->

## 2. Adresses `<adr>` (ce qui est sur le bus d'adresses pendant le cycle)

`PC+` (adresse PC puis PC=PC+1) | `SP` | `SP+` (adresse SP puis SP=SP+1) | `SP+1` | `-SP` (SP=SP-1 puis adresse SP) |
`HL` `BC` `DE` | `NN` (= WZ) | `NN+1` (= WZ+1) | `XY` (IX/IY + d, calcule, memorise dans WZ) | `AN` (port: A sur A15..A8, TMP.L sur A7..A0) | `BC` (port: BC complet).

## Tests
Tous les tests sont prefixes par `e03_05_`.

- `e03_05_pc_inc` : PcInc: renvoie 0x1000 et PC=0x1001; 0xFFFF -> PC=0
- `e03_05_sp_inc` : SpInc: SP=0x2000 renvoie 0x2000 et SP=0x2001
- `e03_05_dec_sp` : DecSp: SP=0x2000 -> renvoie 0x1FFF et SP=0x1FFF; SP=0 -> 0xFFFF
- `e03_05_sp_plus1` : SpPlus1 ne modifie pas SP
- `e03_05_nn` : Nn/NnPlus1 depuis WZ=0xFFFF: 0xFFFF / 0x0000, WZ inchange
- `e03_05_xy_ix` : IX=0x1000, disp=0xFE (-2), Dd: 0x0FFE et WZ=0x0FFE
- `e03_05_xy_iy_pos` : IY=0xFFFF, disp=2 -> 0x0001
- `e03_05_an_port` : A=0x12, TMP.L=0x34 -> 0x1234
- `e03_05_bc_port` : port=true Bc -> BC
