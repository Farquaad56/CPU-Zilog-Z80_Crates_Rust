## Specification
Dans `engine/mod.rs` (impl Engine ou fonctions libres `pub(crate)`):
- `store(&mut self, regs: &mut Regs, r: Reg, v: u8)`: L -> tmp_l, H -> tmp_h, Z -> wz bas (`regs.wz = (regs.wz & 0xFF00) | v`), W -> wz haut, D -> disp, Op -> opb, None -> rien.

## 3. Registres temporaires (internes au moteur)

- `TMP` = (`H`,`L`): donnee lue ou a ecrire. `<dst>` = `L` ou `H`; `<src>` = `L` ou `H`.
- `WZ` = (`W`,`Z`) = registre MEMPTR (adresse operande 16 bits; visible dans les tests SingleStepTests `wz`). `<dst>` = `Z` ou `W`.
- `D` = deplacement signe (octet lu pour `(IX+d)`), `OP` = octet d'opcode lu comme donnee (DD CB d op).

## Tests
Tous les tests sont prefixes par `e03_06_`.

- `e03_06_store_l_h` : store L puis H, load lit les memes valeurs
- `e03_06_store_z_w` : store Z=0x34 puis W=0x12 donne wz=0x1234
- `e03_06_store_d_op` : D et Op stockes dans disp/opb
- `e03_06_none_noop` : Reg::None ne change rien et load renvoie 0
- `e03_06_z_keeps_w` : store Z ne modifie pas l'octet haut de WZ
