## Specification
Dans `crates/puce-z80-machines/src/ssc.rs` (module declare dans lib.rs) : structs serde `Case { name, initial: State, final_: State, cycles: Vec<...> }` conformes au format documente, `State` -> `Cpu` (tous les registres, `wz`, `iff1/2`, `im`, `ei`->`ei_delay`, `q`, `p`...) et `RamMap` (HashMap addr -> octet; lecture d'une adresse absente = 0xFF ou valeur documentee). `load_file(path) -> Vec<Case>`, `apply_initial(&Case) -> (Cpu, SparseBus)`.
Pas de comparaison ici (E13-08).


## Tests
Tous les tests sont prefixes par `e13_07_`.

- `e13_07_parse_sample` : un JSON de 2 cas (ecrit en dur dans le test, copie du format reel) se charge
- `e13_07_apply_regs` : les registres sont recopies (af bc de hl ix iy sp pc i r wz iff im)
- `e13_07_apply_ram` : la RAM sparse contient les paires
- `e13_07_missing_field_error` : un champ obligatoire absent donne une erreur claire
- `e13_07_load_real_file` : charge un fichier reel de tests/roms/singlestep si present (SKIP sinon)
