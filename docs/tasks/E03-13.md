# E03-13 - Test de duree: toutes les instructions (semantique absente)
Epopee: E03 | Type: code | Dependances: E03-12 | Taille estimee: ~100 lignes

## Contexte
Verifie TOUT le timing des plans avant d'ecrire la moindre semantique: avec `sem` vide, `cond` reste faux, donc chaque instruction doit durer `t_min` de sa table.

## Lire d'abord
- `docs/specs/data/main.tsv` lignes 00, 10, 20, C7, CD (recopiees ci-dessous)
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `crates/puce-z80/tests/timing_stub.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Test d'integration `crates/puce-z80/tests/timing_stub.rs` (via `__internal` si besoin). Pour chaque table et chaque opcode non prefixe: place les octets `[prefixes..., opcode, 0x00, 0x00, 0x00]` en RAM (SimpleRam), PC=0x1000, SP=0x8000, execute `step`, compare le resultat a `t_min` du TSV (colonne t_min; lire `docs/specs/data/*.tsv`).
Cas: main (252 hors prefixes), cb (256), ed (256), ddfd (252, prefixe DD puis FD), ddcb (256: octets `DD CB 00 op`, puis `FD CB 00 op`). Les opcodes HALT (76) sont executes 1 fois (4 T).
En cas d'ecart: le message liste table, opcode, mnemonique, attendu, obtenu.

Un echec ici signale un bug du moteur (E03-05..10) ou de la table generee: corrige le moteur, pas la table (la table est verifiee contre la reference).
