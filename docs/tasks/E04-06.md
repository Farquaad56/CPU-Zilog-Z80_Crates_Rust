# E04-06 - Arithmetique 16 bits (ADD HL, ADC HL, SBC HL)
Epopee: E04 | Type: code | Dependances: E04-05 | Taille estimee: ~90 lignes

## Contexte
Les 3 operations 16 bits. `add16` ne touche pas S Z P/V; `adc16`/`sbc16` calculent tous les drapeaux.

## Specification
Dans `alu.rs`: `pub fn add16(a: u16, b: u16, f: u8) -> (u16, u8)`, `pub fn adc16(...)`, `pub fn sbc16(...)` (meme signature). X et Y viennent de l'octet HAUT du resultat. H = retenue du bit 11.
Le test calcule le CRC32 IEEE (poly reflechi 0xEDB88320) des octets produits en suivant EXACTEMENT l'ordre des boucles ci-dessous et le compare a la colonne `crc32` de `docs/specs/data/alu_crc.tsv` (ligne `name`). Ordre: `let mut a = 0u32; while a < 65536 { let mut b = 0u32; while b < 65536 { for f in F_IN { (r, f2) = fn(a as u16, b as u16, f); push (r & 0xFF); push (r >> 8); push f2 } b += 263 } a += 257 }`
avec F_IN = [0x00, 0xFF] pour add16 et [0x00, 0x01] pour adc16/sbc16 (count 128000). Lignes `add16`, `adc16`, `sbc16`.
