## Specification
Ecris `crates/puce-z80-cli/src/commands/bench.rs` (pas de dependance de bench) (`z80 bench --seconds 10`) qui execute une boucle de NOP/LD/ADD/JR en release et affiche T-states/s ('MHz equivalent'). Mesure; si < 15 MHz equivalent, optimise SANS changer le comportement : (1) evite les recherches de table par jeton (pointeur direct), (2) `#[inline]` sur les chemins chauds de `tick`, (3) evite les `match` sur Kind repetes (precalcule la fonction de broches du jeton), (4) pas d'allocation, (5) hors feature `inspect` aucun cout. Toute optimisation garde les tests (diff, ssc, fuse) verts. Consigne les mesures avant/apres dans `docs/qa/FAQ_Z80.md` section `## Performance`.
