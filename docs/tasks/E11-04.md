## Specification
`DD`/`FD` : modele `MNEM_DDFD` avec `IX` (DD) ou `IY` (FD) (le modele contient 'IX' ; remplace par 'IY' pour FD, y compris IXH/IXL -> IYH/IYL). `d` signe. Les modeles '(prefix ignored) X' s'affichent `DD` suivi de la suite : pour une ligne 'prefix ignored', le desassembleur renvoie `DD` seul (len 1) - c'est le comportement reel (le prefixe est une instruction de 4 T). DDCB : format `MNEM_DDCB` avec `d` apres DD CB, len 4.
