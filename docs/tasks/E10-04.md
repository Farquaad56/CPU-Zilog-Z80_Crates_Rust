# E10-04 - NMOS: LD A,I / LD A,R et interruption
Epopee: E10 | Type: code | Dependances: E10-03 | Taille estimee: ~60 lignes

## Contexte
Bug NMOS documente : si une INT est acceptee immediatement apres `LD A,I` ou `LD A,R`, P/V est mis a 0 au lieu de IFF2 (D-006).

## Specification
Ajoute `eng.last_ld_air: bool` (vrai si la derniere instruction terminee est `ED 57` ou `ED 5F`, remis a false a la fin de toute autre instruction). Dans `start_int()` (E09-05) : si `last_ld_air` alors `regs.f &= !PV` avant d'empiler. La NMI n'est pas concernee. Le test doit utiliser un bus qui declenche `irq()` juste apres l'instruction.

## 4. EI / DI / LD A,I

- `EI`: IFF1=IFF2=1, mais l'acceptation d'INT est retardee d'une instruction.
- `LD A,I` / `LD A,R`: P/V = IFF2. (U) NMOS: si une INT est acceptee juste apres cette instruction, P/V est remis a 0 (bug NMOS documente).
<!-- end -->

## Tests
Tous les tests sont prefixes par `e10_04_`.

- `e10_04_int_after_ld_a_i` : P/V=0 apres l'acceptation (IFF2 = 1)

- `e10_04_int_after_nop_keeps` : pas de modification apres un NOP
- `e10_04_nmi_not_affected` : NMI apres LD A,I: P/V inchange
