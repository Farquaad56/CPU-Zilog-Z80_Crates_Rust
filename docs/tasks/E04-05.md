## Specification
Dans `alu.rs`: `pub fn rot(y: u8, v: u8, f: u8) -> (u8, u8)` avec y = 0 RLC, 1 RRC, 2 RL, 3 RR, 4 SLA, 5 SRA, 6 SLL, 7 SRL. Renvoie (resultat, F complet: S Z X Y depuis le resultat, H=N=0, P/V parite, C = bit sorti).
Le test calcule le CRC32 IEEE (poly reflechi 0xEDB88320) des octets produits en suivant EXACTEMENT l'ordre des boucles ci-dessous et le compare a la colonne `crc32` de `docs/specs/data/alu_crc.tsv` (ligne `name`). Ordre: `for v in 0..=255 { for c in 0..=1 { (r,f)=rot(y,v,c); push r; push f } }` (count 512). Lignes: `rot_rlc rot_rrc rot_rl rot_rr rot_sla rot_sra rot_sll rot_srl`.

## Rotations et decalages (RLC RRC RL RR SLA SRA SLL SRL)

```js
  rot(y,v){
    let c,res;
    switch(y){
      case 0:c=v>>7;res=((v<<1)|c)&255;break;
      case 1:c=v&1;res=(v>>1)|(c<<7);break;
      case 2:c=v>>7;res=((v<<1)|(this.r[6]&1))&255;break;
      case 3:c=v&1;res=(v>>1)|((this.r[6]&1)<<7);break;
      case 4:c=v>>7;res=(v<<1)&255;break;
      case 5:c=v&1;res=(v>>1)|(v&0x80);break;
      case 6:c=v>>7;res=((v<<1)|1)&255;break;
      default:c=v&1;res=v>>1;
    }
    this.aOp=ROTN[y];this.aW=8;this.aA=v;this.aB=0;this.aC=this.r[6]&1;this.aR=res;this.aF=this.r[6];
    this.r[6]=(res&0xA8)|(res?0:FZ)|PAR[res]|c;return res;
  }
```
