# E16-05 - Plusieurs CPU, determinisme et no_std
Epopee: E16 | Type: code | Dependances: E16-04 | Taille estimee: ~110 lignes

## Contexte
Bornes d'arcade a plusieurs Z80 (Galaga) ; portabilite embarquee/WASM.

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `crates/puce-z80/tests/multi_cpu.rs`
- `tools/nostd_check.sh`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
- Test `tests/multi_cpu.rs` : deux `Cpu` avec deux RAM executent le meme programme entrelaces tick par tick (A puis B) : resultats identiques a deux executions separees ; aucun `static mut`/etat global (grep dans `src/`).
- Test de determinisme : deux executions de 1 million de T-states sur le meme programme donnent le meme hachage d'etat.
- Script `tools/nostd_check.sh` : `rustup target add thumbv7em-none-eabihf` puis `cargo build -p puce-z80 --target thumbv7em-none-eabihf` (SKIP avec message si la cible n'est pas installable: pas de reseau) ; en plus verifie `cargo build -p puce-z80 --target wasm32-unknown-unknown` si la cible est installee.


## Tests
Tous les tests sont prefixes par `e16_05_`.

- `e16_05_two_cpus_interleaved` : entrelaces == separes
- `e16_05_deterministic_hash` : hachage stable
- `e16_05_no_global_state` : aucun static mut dans src

## Acceptance
```acceptance
cargo test -p puce-z80 e16_05_
bash tools/nostd_check.sh
```
