## Specification
Cree `crates/puce-z80/src/alu.rs` (`pub mod alu;`, fonctions `pub`, documentees):
`pub fn alu8(op: u8, a: u8, b: u8, f: u8) -> (u8, u8)` : `op` 0..7 = ADD ADC SUB SBC AND XOR OR CP. Renvoie `(nouvel A, nouveau F)` (pour CP, A inchange; X et Y de F viennent de l'OPERANDE b). Dans cette tache implemente 0 (ADD), 1 (ADC), 2 (SUB), 3 (SBC), 7 (CP); les autres valeurs: `unreachable!()` pour l'instant (E04-03).
`pub fn parity(v: u8) -> u8` (0x04 si nombre de bits pair, sinon 0). Utilise `crate::regs::flag`.
Le test calcule le CRC32 IEEE (poly reflechi 0xEDB88320) des octets produits en suivant EXACTEMENT l'ordre des boucles ci-dessous et le compare a la colonne `crc32` de `docs/specs/data/alu_crc.tsv` (ligne `name`).
Ordre (pour op = 0..): `for a in 0..=255 { for b in 0..=255 { for c in 0..=1 { f_in = c; (A', F') = alu8(op, a, b, c); push A'; push F' } } }` -> count 131072. Noms de lignes: `alu8_add`, `alu8_adc`, `alu8_sub`, `alu8_sbc`, `alu8_cp`.

  alu(y,v){
    const r=this.r,a=r[7],f=r[6];let res,nf;
    this.aOp=ALUN[y];this.aW=8;this.aA=a;this.aB=v;this.aC=(y===1||y===3)?(f&1):0;this.aF=f;
    switch(y){
      case 0:case 1:{const c=y&&(f&1);const t=a+v+c;res=t&255;nf=(res&0xA8)|(res?0:FZ)|((a^v^res)&FH)|(((a^res)&(v^res)&0x80)?FP:0)|(t>>8);break;}
      case 2:case 3:case 7:{const c=y===3?(f&1):0;const t=a-v-c;res=t&255;const xy=y===7?v:res;nf=(xy&0x28)|(res&0x80)|(res?0:FZ)|((a^v^res)&FH)|(((a^v)&(a^res)&0x80)?FP:0)|FN|((t>>8)&1);break;}
