# E13-21 - Baseline et resume global des suites
Epopee: E13 | Type: code | Dependances: E13-20 | Taille estimee: ~100 lignes

## Contexte
Une commande unique `z80 suite all` lance toutes les suites disponibles et ecrit un resume machine-lisible (utilise pour le GATE et la CI de release).

- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Specification
`z80 suite all [--skip zexall,...] [--json out.json]` : lance prelim, zexdoc, zexall, ssc (cycles), fuse, z80test (6), timing ROMs, diff.tsv (appel `cargo test` impossible: reimplemente un appel direct au banc via la lib de machines ou lance `cargo test` en sous-processus) ; chaque suite : `PASS | FAIL | SKIP(reason) | UNAVAILABLE`. Sortie JSON `{suites:[{name,status,details,seconds}]}`, code 0 si aucune FAIL et aucune SKIP des suites obligatoires (prelim, zexdoc, zexall, ssc, fuse, z80test). Ecris `docs/tools/suites_report.py` qui transforme le JSON en tableau Markdown `docs/SUITES_REPORT.md`.


## Tests
Tous les tests sont prefixes par `e13_21_`.

- `e13_21_all_skip_missing` : sans aucune ROM: toutes SKIP et code != 0
- `e13_21_json_shape` : le JSON a le champ suites avec name/status
- `e13_21_skip_flag` : --skip exclut une suite
- `e13_21_report_table` : suites_report.py produit un tableau
