# E01-05 - Type Pins (broches du Z80)
Epopee: E01 | Type: code | Dependances: E01-04 | Taille estimee: ~110 lignes

## Contexte
Representation des broches du CPU sur 64 bits, en logique positive (D-011). C'est l'interface a la fois du CPU (`tick`) et des hotes (emulateurs de consoles/arcade).

## Specification
Dans `crates/puce-z80/src/pins.rs` (decommente `pub mod pins;` dans lib.rs et re-exporte `pub use pins::Pins;`):
```rust
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Hash)]
pub struct Pins(pub u64);
impl Pins {
    pub const A_MASK: u64 = 0xFFFF; pub const D_SHIFT: u32 = 16; pub const D_MASK: u64 = 0xFF << 16;
    pub const M1: u64 = 1 << 24; pub const MREQ: u64 = 1 << 25; pub const IORQ: u64 = 1 << 26; pub const RD: u64 = 1 << 27; pub const WR: u64 = 1 << 28;
    pub const HALT: u64 = 1 << 29; pub const WAIT: u64 = 1 << 30; pub const INT: u64 = 1 << 31; pub const NMI: u64 = 1 << 32;
    pub const RFSH: u64 = 1 << 33; pub const BUSRQ: u64 = 1 << 34; pub const BUSAK: u64 = 1 << 35; pub const RESET: u64 = 1 << 36;
    pub const fn addr(self) -> u16; pub const fn data(self) -> u8; pub const fn set_addr(self, a: u16) -> Pins; pub const fn set_data(self, d: u8) -> Pins;
    pub const fn has(self, mask: u64) -> bool;   // TOUS les bits du masque sont a 1
    pub const fn with(self, mask: u64) -> Pins;  pub const fn without(self, mask: u64) -> Pins;
    pub const fn is_mem_read(self) -> bool;  // MREQ et RD
    pub const fn is_mem_write(self) -> bool; pub const fn is_io_read(self) -> bool; pub const fn is_io_write(self) -> bool;
    pub const fn is_fetch(self) -> bool;     // M1 et MREQ et RD
    pub const fn is_int_ack(self) -> bool;   // M1 et IORQ
}
impl core::fmt::LowerHex for Pins {}  // affiche `0x` + hex de la valeur u64 (utile au debug)
```
Toutes les fonctions sont `const fn`, documentees.

## 1. Type `Pins` (u64, logique positive: bit a 1 = signal actif, meme pour les broches actives a l'etat bas du vrai Z80)

| Bits | Nom | Sens |
|---|---|---|
| 0..15 | A0..A15 | bus d'adresses (sortie) |
| 16..23 | D0..D7 | bus de donnees (entree ET sortie) |
| 24 | M1 | sortie |
| 25 | MREQ | sortie |
| 26 | IORQ | sortie |
| 27 | RD | sortie |
| 28 | WR | sortie |
| 29 | HALT | sortie |
| 30 | WAIT | entree |
| 31 | INT | entree |
| 32 | NMI | entree |
| 33 | RFSH | sortie |
| 34 | BUSRQ | entree |
| 35 | BUSAK | sortie |
| 36 | RESET | entree |

`Pins` est un newtype `pub struct Pins(pub u64)` avec des constantes `Pins::M1` etc. (masques) et des accesseurs `addr()`, `set_addr()`, `data()`, `set_data()`.

## Tests
Tous les tests sont prefixes par `e01_05_`.

- `e01_05_addr_data_roundtrip` : set_addr/set_data puis addr()/data() pour 0x0000, 0xFFFF, 0x1234 et 0x00, 0xFF, 0xA5; les autres bits ne changent pas
- `e01_05_masks_distinct` : les 13 masques de controle sont deux a deux disjoints et disjoints de A et D
- `e01_05_fetch_predicate` : M1|MREQ|RD -> is_fetch vrai; MREQ|RD seul -> is_fetch faux, is_mem_read vrai
- `e01_05_int_ack_predicate` : M1|IORQ -> is_int_ack vrai; IORQ|RD -> is_io_read vrai
- `e01_05_with_without` : with puis without restitue la valeur initiale
- `e01_05_hex_fmt` : format!("{:x}", Pins(0x1F)) == "0x1f"
