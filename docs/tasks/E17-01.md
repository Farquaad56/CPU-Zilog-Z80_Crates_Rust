# E17-01 - CI de release et changelog
Epopee: E17 | Type: tooling | Dependances: E16-07 | Taille estimee: ~60 lignes

## Contexte
Preparer la version 0.1.0.

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `tools/release_check.sh`
- `CHANGELOG.md`
- `crates/puce-z80/Cargo.toml`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
- `tools/release_check.sh` : `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `bash tools/hygiene.sh`, `cargo build --release --workspace`, `cargo run --release -p puce-z80-cli -- suite all --json suites.json`, `python docs/tools/suites_report.py suites.json`.
- `CHANGELOG.md` (anglais) : v0.1.0, fonctionnalites, suites validees (copie du tableau de `docs/SUITES_REPORT.md`).
- Verifie `crates/puce-z80/Cargo.toml` : `description`, `license`, `keywords`, `categories` (`emulators`, `no-std`), `repository` laisse vide (UNKNOWN - to confirm, a remplir par l'utilisateur).
