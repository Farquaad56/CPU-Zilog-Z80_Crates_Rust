# E13-06 - SingleStepTests/z80: decouvrir et documenter le format
Epopee: E13 | Type: doc | Dependances: E13-05 | Taille estimee: ~0 lignes

## Contexte
SingleStepTests/z80 fournit, pour chaque opcode, des milliers de cas JSON (etat initial, etat final, liste de cycles de bus). Le format exact n'est pas dans ce depot : il faut le LIRE sur les vrais fichiers.

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `docs/specs/33_SINGLESTEP_FORMAT.md`
- `docs/specs/11_PINS_AND_TICK.md`
- `docs/qa/FAQ_Z80.md`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
1. `git clone --depth 1 https://github.com/SingleStepTests/z80 tests/roms/singlestep` (si l'URL est fausse: cherche le depot exact et note-le).
2. Lis le README du depot et OUVRE 3 fichiers de test (par ex. un NOP, un `LD A,(nn)`, un `DD CB`). Ecris `docs/specs/33_SINGLESTEP_FORMAT.md` (ASCII, francais) qui decrit : la structure des dossiers, le nom des fichiers (par opcode, prefixes), les champs JSON (`name`, `initial`, `final`, `cycles`, `ports`...), l'encodage de `ram` (paires [addr, val]), les registres presents (`wz`, `iff1`, `iff2`, `im`, `ei`, `p`, `q`, `af_`, ...), la forme exacte d'un element de `cycles` (adresse, donnee, broches sous forme de chaine type `read`/`write`/`---`), le nombre de cas par fichier, et les cas particuliers (HALT, interruptions, ports).
3. Ajoute une section `## Convention de broches observee` : pour 3 instructions, recopie la liste des cycles du JSON a cote de ce que produit `fmt_trace` (E03-14), et liste les differences.
4. Mets a jour `docs/specs/11_PINS_AND_TICK.md` ligne `UNKNOWN - to confirm` du paragraphe 3 en renvoyant vers ce nouveau fichier. N'ecris PAS de code Rust.


### Notes
Tout ce qui est marque `UNKNOWN - to confirm` DOIT etre verifie sur la source reelle (git clone --depth 1 / curl) puis documente dans le fichier indique; si la source est inaccessible depuis le reseau de la machine: question Q&R (docs/02_QA_PROTOCOL.md), ne rien inventer.
