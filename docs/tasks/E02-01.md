## Specification
Cree `crates/puce-z80/src/engine/mod.rs` (vide sauf `pub mod plan;`) et `engine/plan.rs`; dans lib.rs: `pub(crate) mod engine;`.
```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Kind { F, R, W, N, O, I, X }   // F=M1 R=lecture W=ecriture N=lecture port O=ecriture port I=interne X=hook
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Addr { None, PcInc, Sp, SpInc, SpPlus1, DecSp, Hl, Bc, De, Nn, NnPlus1, Xy, An }
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Reg { None, L, H, Z, W, D, Op }     // cible/source: TMP.L TMP.H WZ.Z WZ.W deplacement octet-opcode-donnee
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct Tok { pub kind: Kind, pub len: u8, pub addr: Addr, pub reg: Reg, pub cond: bool }
impl Tok { pub const fn new(kind: Kind, len: u8, addr: Addr, reg: Reg, cond: bool) -> Tok }
pub type Plan = &'static [Tok];
impl Tok { pub const fn is_hook(&self) -> bool; pub const fn is_bus(&self) -> bool /* F R W N O */ }
pub fn plan_t_min(p: Plan) -> u32   // somme des len des jetons NON conditionnels
pub fn plan_t_max(p: Plan) -> u32   // somme de tous les jetons
```
Pour un hook, le generateur emet `Tok::new(Kind::X, 0, ...)` pour X0 et `Tok::new(Kind::X, 1, ...)` pour X1. Documente-le: pour `Kind::X`, `len` = numero du hook (0 ou 1) et dure 0 T; ajoute `pub const fn hook_no(&self) -> u8`. `plan_t_*` doivent donc ignorer `Kind::X`.

## 1. Jetons

| Jeton | Sens | T-states |
|---|---|---|
| `F4` `F5` `F6` | cycle M1 (lecture d'opcode ou de prefixe + refresh). `F5`/`F6` = M1 etendu (T supplementaires internes) | 4/5/6 |
| `R3:<adr>><dst>` `R4` `R5` | lecture memoire a `<adr>` vers `<dst>`; 3 T normal, 4/5 = T internes en plus | 3/4/5 |
| `W3:<adr><src>` `W5` | ecriture memoire de `<src>` a `<adr>` | 3/5 |
| `N4:<adr>><dst>` | lecture de port (IN) | 4 |
| `O4:<adr><src>` | ecriture de port (OUT) | 4 |
| `I<n>` | cycle interne de `n` T-states (aucune activite de bus) | n |
| `X0` `X1` | **hook**: appelle `sem(op_table, opcode, hook)`; dure 0 T | 0 |
| prefixe `?` | le jeton n'est execute que si le drapeau interne `cond` est vrai (positionne par X0) | 0 si saute |

## 2. Adresses `<adr>` (ce qui est sur le bus d'adresses pendant le cycle)

`PC+` (adresse PC puis PC=PC+1) | `SP` | `SP+` (adresse SP puis SP=SP+1) | `SP+1` | `-SP` (SP=SP-1 puis adresse SP) |
`HL` `BC` `DE` | `NN` (= WZ) | `NN+1` (= WZ+1) | `XY` (IX/IY + d, calcule, memorise dans WZ) | `AN` (port: A sur A15..A8, TMP.L sur A7..A0) | `BC` (port: BC complet).
<!-- end -->

<!-- begin docs/specs/12_PLAN_GRAMMAR.md#3. Registres -->
## 3. Registres temporaires (internes au moteur)

- `TMP` = (`H`,`L`): donnee lue ou a ecrire. `<dst>` = `L` ou `H`; `<src>` = `L` ou `H`.
- `WZ` = (`W`,`Z`) = registre MEMPTR (adresse operande 16 bits; visible dans les tests SingleStepTests `wz`). `<dst>` = `Z` ou `W`.
- `D` = deplacement signe (octet lu pour `(IX+d)`), `OP` = octet d'opcode lu comme donnee (DD CB d op).
<!-- end -->
