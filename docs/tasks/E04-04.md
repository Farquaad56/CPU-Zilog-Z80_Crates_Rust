## Specification
Dans `alu.rs`: `pub fn inc8(v: u8, f: u8) -> (u8, u8)` et `pub fn dec8(v: u8, f: u8) -> (u8, u8)` (renvoient (resultat, F)).
Le test calcule le CRC32 IEEE (poly reflechi 0xEDB88320) des octets produits en suivant EXACTEMENT l'ordre des boucles ci-dessous et le compare a la colonne `crc32` de `docs/specs/data/alu_crc.tsv` (ligne `name`). Ordre: `for v in 0..=255 { for c in 0..=1 { (r, f) = inc8(v, c); push r; push f } }` (count 512). Lignes `inc8`, `dec8`.

## INC et DEC 8 bits

```js
  inc8(v){const f=this.r[6];const res=(v+1)&255;this.aOp='INC';this.aW=8;this.aA=v;this.aB=1;this.aC=0;this.aR=res;this.aF=f;
    this.r[6]=(f&FC)|(res&0xA8)|(res?0:FZ)|((res&15)===0?FH:0)|(res===0x80?FP:0);return res;}

  dec8(v){const f=this.r[6];const res=(v-1)&255;this.aOp='DEC';this.aW=8;this.aA=v;this.aB=1;this.aC=0;this.aR=res;this.aF=f;
    this.r[6]=(f&FC)|(res&0xA8)|(res?0:FZ)|((res&15)===15?FH:0)|(res===0x7F?FP:0)|FN;return res;}
```

## Tests
Tous les tests sont prefixes par `e04_04_`.

- `e04_04_inc8` : CRC inc8
- `e04_04_dec8` : CRC dec8
- `e04_04_inc_overflow` : inc8(0x7F,0) a P/V=1 et H=1
- `e04_04_dec_overflow` : dec8(0x80,0) a P/V=1
- `e04_04_carry_kept` : inc8(0xFF,1) conserve C=1
