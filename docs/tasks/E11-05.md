# E11-05 - Desassembleur: longueur coherente avec les plans
Epopee: E11 | Type: code | Dependances: E11-04 | Taille estimee: ~70 lignes

## Contexte
Garde-fou : la longueur desassemblee d'une instruction doit etre egale au nombre d'octets que le moteur lit reellement.

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `crates/puce-z80/tests/disasm_len.rs`
- `crates/puce-z80/src/disasm.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Test d'integration `tests/disasm_len.rs` (feature disasm) : pour chaque opcode de chaque table (via `__internal::plan_of`), calcule la longueur 'moteur' = nombre de jetons `PcInc` + nombre de jetons F (compte 1 octet chacun) pour les plans non vides ; verifie `disassemble(...).len`. Exceptions explicites : lignes `prefix ignored` (len 1) et `DDCB` (4). Teste aussi que le texte n'est jamais vide et ne contient que de l'ASCII imprimable.


## Tests
Tous les tests sont prefixes par `e11_05_`.

- `e11_05_main_len` : 252 opcodes main
- `e11_05_cb_ed_len` : 512 opcodes
- `e11_05_ddfd_len` : DD et FD
- `e11_05_ddcb_len` : DDCB et FDCB
- `e11_05_text_ascii` : ASCII imprimable non vide
