# E04-01 - Harnais CRC des primitives ALU
Epopee: E04 | Type: code | Dependances: E03-15 | Taille estimee: ~100 lignes

## Contexte
L'ALU Rust (`alu.rs`) est une suite de fonctions PURES sur des entiers. Elle est validee de facon EXHAUSTIVE hors-ligne par des CRC32 de resultats produits par le coeur de reference (qui passe ZEXALL). Cette tache cree le harnais; les taches suivantes ajoutent une fonction ALU et son test CRC chacune.

## Lire d'abord
- `docs/specs/data/alu_crc.tsv` (24 lignes: name, count, crc32)
- `docs/tools/gen_alu_crc.js` (le generateur: source de l'ordre des boucles, ne PAS le modifier)
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `crates/puce-z80/tests/common/**`
- `crates/puce-z80/tests/alu_crc.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Cree `crates/puce-z80/tests/common/mod.rs` (declare `pub mod crc; pub mod tsv;` + re-exports) et:
- `common/crc.rs`: `pub struct Crc32(u32)` avec `new()`, `update(&mut self, b: u8)`, `finish(self) -> u32`; `pub fn crc32(data: &[u8]) -> u32`. Table calculee a la volee (const fn ou tableau local).
- `common/tsv.rs`: `pub fn read_tsv(rel: &str) -> Vec<Vec<String>>` lit `docs/specs/data/<rel>` (chemin base sur `env!("CARGO_MANIFEST_DIR")/../../docs/specs/data/`), saute la ligne d'en-tete, decoupe sur la tabulation. `pub fn alu_crc(name: &str) -> (u64, u32)` renvoie (count, crc) de la ligne `name` (panic clair si absente).
- `tests/alu_crc.rs` (`mod common;`) : les helpers ci-dessus + fonction `fn check(name: &str, bytes_crc: Crc32, count: u64)` qui compare crc ET count a la table (message: nom, attendu, obtenu).
Les futures taches ajouteront des fonctions `#[test] fn e04_NN_<name>()` dans `tests/alu_crc.rs`.


## Tests
Tous les tests sont prefixes par `e04_01_`.

- `e04_01_crc_known_vector` : crc32(b"123456789") == 0xCBF43926
- `e04_01_crc_empty` : crc32(b"") == 0
- `e04_01_incremental_equals_oneshot` : update octet par octet == crc32 d'un bloc
- `e04_01_tsv_has_24_rows` : read_tsv("alu_crc.tsv") a 24 lignes
- `e04_01_alu_crc_lookup` : alu_crc("alu8_add") == (131072, 0x09ee0e62)
- `e04_01_tsv_missing_panics` : alu_crc("nope") panique (#[should_panic])
