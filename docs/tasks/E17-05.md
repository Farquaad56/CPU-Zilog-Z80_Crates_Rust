## Specification
`puce-z80` compile tel quel pour `wasm32-unknown-unknown` (no_std, sans dependance). Le crate `crates/puce-z80-wasm` (cdylib + rlib, `wasm-bindgen`) expose la classe JS `Z80` (`load_demo`, `load`, `step`, `run`, `regs`, `peek`, `take_output`) au-dessus de `Machine` (RAM 64 Ko, `OUT (0),A` ecrit un caractere). `demo/index.html` charge le module genere par `wasm-bindgen --target web`. Tests `e17_05_*` sur `Machine`/`Z80` (hote) et build des deux crates pour la cible wasm.
