# E13-08 - SingleStepTests: comparaison de l'etat final
Epopee: E13 | Type: code | Dependances: E13-07 | Taille estimee: ~140 lignes

## Contexte
Execute chaque cas avec `Cpu::step` et compare l'etat final (registres, RAM, WZ, Q...) avec `final`.

## Specification
- `z80 ssc <dir> [--filter 00,dd/21] [--max-fail N]` : pour chaque fichier/cas, `apply_initial`, `step`, `diff_final(&Case, &Cpu, &SparseBus) -> Vec<String>` (liste lisible des ecarts : champ, attendu, obtenu) ; resume par opcode (cas passes/total) ; code de retour 1 si ecart.
- Compare : registres 8/16 bits, `wz`, `iff1`, `iff2`, `im`, `r`, `i`, `q`, RAM (adresses du `final.ram` ET toute ecriture parasite), ports si presents. Les cycles de bus (pins) NE SONT PAS compares ici (E13-09).
- Les ecarts sur HALT (convention de PC, D-022), SCF/CCF (Q) et WZ des instructions de bloc sont attendus au debut : liste-les dans `tests/baseline.json` (`{"known_failures": ["<opcode>", ...]}`) avec une raison, au lieu de les masquer.


## Tests
Tous les tests sont prefixes par `e13_08_`.

- `e13_08_diff_final_reports` : un etat final volontairement faux donne des ecarts nommes
- `e13_08_diff_final_ok` : un etat correct donne une liste vide
- `e13_08_summary_format` : le resume par opcode est stable (une ligne par opcode)
- `e13_08_filter` : --filter limite aux opcodes demandes
