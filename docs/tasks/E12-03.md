## Specification
`Cpu::last_bus(&self) -> BusView { addr: u16, data: u8, kind: u8 /*0 fetch 1 read 2 write 3 io-read 4 io-write*/, pins: Pins }` : dernier cycle de bus COMPLET (mis a jour au tick ou la donnee est latchee/ecrite). Feature `inspect`.


## Tests
Tous les tests sont prefixes par `e12_03_`.

- `e12_03_fetch_view` : apres NOP: kind 0, addr 0
- `e12_03_write_view` : apres LD (HL),A: kind 2 avec la donnee
- `e12_03_io_view` : apres OUT (n),A: kind 4
- `e12_03_read_view` : LD A,(nn): kind 1
