# E02-02 - Generer et integrer les tables de plans
Epopee: E02 | Type: tooling | Dependances: E02-01 | Taille estimee: ~40 lignes

## Contexte
Les 5 tables de plans (`main`, `cb`, `ed`, `ddfd`, `ddcb`) sont GENEREES depuis `docs/specs/data/*.tsv`: personne ne les ecrit a la main.

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `crates/puce-z80/src/tables/**`
- `crates/puce-z80/src/lib.rs`
- `docs/tools/gen_rust_tables.py`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
1. Lance `python docs/tools/gen_rust_tables.py` depuis la racine du depot (cree `crates/puce-z80/src/tables/{main,cb,ed,ddfd,ddcb,mnem,mod}.rs`).
2. Dans lib.rs ajoute `pub(crate) mod tables;`. Le fichier `tables/mnem.rs` est sous `#[cfg(feature = "disasm")]` (declare dans `tables/mod.rs`).
3. Verifie que `cargo build -p puce-z80` ET `cargo build -p puce-z80 --features disasm` compilent sans avertissement. Si un avertissement `dead_code` apparait, ajoute `#![allow(dead_code)]` EN TETE de `tables/mod.rs` UNIQUEMENT (fichier genere: modifie plutot le generateur `docs/tools/gen_rust_tables.py` si besoin, et relance-le).
4. Ne modifie JAMAIS a la main les fichiers generes. Si le generateur est faux, pose une question Q&R.
