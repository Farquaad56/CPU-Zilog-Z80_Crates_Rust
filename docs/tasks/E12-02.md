Epopee: E12 | Type: code | Dependances: E12-01 | Taille estimee: ~110 lignes

## Specification
Dans `probe.rs` : `pub struct History { pc: [u16; 32], head: u8, count: u8 }` (anneau, plus recents d'abord via `iter()`), `pub struct WriteLog { addr: [u16; 32], ... }` (anneau). Sur `Cpu` (feature inspect) : `pub fn pc_history(&self) -> impl Iterator<Item = u16>` (PC de DEBUT des 32 dernieres instructions, plus recente en premier), `pub fn recent_writes(&self) -> impl Iterator<Item = u16>`, `pub fn instruction_count(&self) -> u64`, `pub fn tstate_count(&self) -> u64`. L'historique est mis a jour au debut de chaque instruction non-HALTee; le journal d'ecritures a chaque jeton W reellement emis. Pas d'alloc.


## Tests
Tous les tests sont prefixes par `e12_02_`.

- `e12_02_history_order` : apres 3 NOP: [2,1,0] en premier
- `e12_02_history_wraps` : 100 NOP: 32 entrees, plus recente d'abord
- `e12_02_write_log` : LD (HL),A enregistre l'adresse
- `e12_02_counters` : instruction_count et tstate_count apres LD BC,nn: 1 et 10
- `e12_02_halt_not_counted` : les NOP de HALT ne polluent pas l'historique
