# E17-03 - Variante CMOS
Epopee: E17 | Type: code | Dependances: E17-02 | Taille estimee: ~120 lignes

## Contexte
Hors v1 (D-006). Variante CMOS du Z80 (ex. Zilog Z84C00) : `OUT (C),0` ecrit 0xFF, SCF/CCF sans facteur Q, pas de bug `LD A,I`, `LD A,I` etc.

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `crates/puce-z80/src/**`
- `crates/puce-z80/tests/variant.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Ajoute `enum Variant { Nmos, Cmos }` (defaut Nmos), `Cpu::with_variant(v)` et `Cpu::variant()`. Differences CMOS (D-028), localisees dans `sem/**` et `int.rs`: (1) `OUT (C),0` (ED 71) ecrit 0xFF; (2) pas de bug P/V de `LD A,I`/`LD A,R` suivi d'une INT; (3) SCF/CCF sans facteur Q (X/Y = A or F). Tests dans `crates/puce-z80/tests/variant.rs`.
