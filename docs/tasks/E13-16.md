# E13-16 - Machine ZX Spectrum minimale
Epopee: E13 | Type: code | Dependances: E13-15 | Taille estimee: ~150 lignes

## Contexte
Machine ZX Spectrum 48K minimale pour executer z80test et les ROMs de timing : ROM 16 Ko fournie par l'utilisateur, RAM 48 Ko, port 0xFE (clavier = rien, bordure ignoree), chargement rapide de bande, capture du texte.

## Specification
Dans `crates/puce-z80-machines/src/zx.rs` : `ZxMachine { cpu, mem: [u8; 65536], rom_loaded, tap, out: String, ... }` ; `new(rom: &[u8])` (refuse si != 16384 octets) ; `step()` ; interruption 50 Hz generee tous les 69888 T-states (INT pendant 32 T) ; `Bus::io_read(0xFE)` renvoie 0xBF (pas de touche) ; **fast-load** : quand `PC == 0x0556` (LD-BYTES) copie le bloc suivant du .tap vers l'adresse DE, longueur IX/DE, positionne les registres comme le ROM a la sortie (carry set = succes) puis simule RET ; capture de sortie : `PC == 0x0010` (RST 10h, caractere dans A) ajoute a `out`. Contention de la memoire (extra_wait) en OPTION (`with_contention(bool)`) : table standard des 6 T-states de motif sur 8 pour les adresses 0x4000-0x7FFF pendant les lignes d'ecran (UNKNOWN - to confirm, necessaire seulement pour les ROMs de timing, E13-19).
`load_tap(bytes)` parse les blocs `.tap` (flag, donnees, checksum).


## Tests
Tous les tests sont prefixes par `e13_16_`.

- `e13_16_rom_size_check` : ROM de mauvaise taille refusee
- `e13_16_tap_parse` : un .tap de 2 blocs en dur est parse
- `e13_16_fastload_copies_block` : avec une fausse ROM contenant CALL 0556h, le bloc est copie a DE
- `e13_16_rst10_capture` : un programme qui fait RST 10h avec A='X' capture 'X'
- `e13_16_frame_interrupt` : apres 69888 T l'INT est genere
- `e13_16_io_fe` : IN A,(FE) renvoie 0xBF
