## Specification
Dans `crates/puce-z80-machines/src/fuse.rs` : parseurs (texte), `FuseTest { name, regs, mem_blocks, tstates }`, `FuseExpected { events, regs, mem_changes }`, executeur `run_fuse(test) -> FuseResult` : execute des instructions jusqu'a ce que le total de T-states atteigne `tstates` du test (regle FUSE: l'instruction qui franchit la limite est executee), enregistre les evenements de bus (T-state, type, adresse, donnee) via `Bus::on_tick`/le journal et compare avec `expected`. `z80 fuse <dir>` affiche les echecs et le resume.


## Tests
Tous les tests sont prefixes par `e13_13_`.

- `e13_13_parse_in` : un enregistrement tests.in en dur est parse
- `e13_13_parse_expected` : un enregistrement tests.expected en dur est parse
- `e13_13_run_nop` : le test NOP (00) passe
- `e13_13_event_order` : les evenements d'un LD A,(nn) sont MC/MR dans l'ordre FUSE
- `e13_13_mismatch_reported` : un evenement faux est signale avec son T-state
