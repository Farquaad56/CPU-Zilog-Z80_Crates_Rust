# E03-14 - Journal de broches par T-state (outil de debug)
Epopee: E03 | Type: code | Dependances: E03-13 | Taille estimee: ~80 lignes

## Contexte
Outil pour les futures taches de calage (SingleStepTests) : enregistrer les broches de chaque T-state d'une instruction.

- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Specification
Dans `crates/puce-z80/tests/common/trace.rs` (module de test partage, `mod common;` dans les tests): `pub fn trace_instruction(bytes: &[u8], setup: impl Fn(&mut Cpu)) -> Vec<Pins>` execute une instruction sur une RAM de test et renvoie les `Pins` de sortie de chaque tick; `pub fn fmt_trace(&[Pins]) -> String` (une ligne par T: `T3 A=0001 D=34 M1 MREQ RD`).
Test d'integration `crates/puce-z80/tests/trace_basic.rs`.


## Tests
Tous les tests sont prefixes par `e03_14_`.

- `e03_14_nop_trace_len` : 4 lignes pour NOP
- `e03_14_nop_trace_fetch` : ligne 2 contient M1 MREQ RD
- `e03_14_refresh_line` : ligne 3 contient RFSH
- `e03_14_fmt_has_t` : fmt_trace commence par `T1`
- `e03_14_ld_rp_nn_trace` : 10 lignes
