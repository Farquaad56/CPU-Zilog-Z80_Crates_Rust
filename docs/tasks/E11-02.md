## Specification
Complete `disassemble` pour `MNEM_MAIN` et `MNEM_CB` : remplace `nn`, `n`, `e` dans le modele (attention `nn` avant `n`), calcule `len` (1 + nombre d'octets d'operande : nn=2, n=1, e=1), prefixe CB -> len 2. Les modeles contiennent aussi des noms de registres contenant 'n' (ex. 'INC', 'NZ') : remplace uniquement les jetons ISOLES `nn`, `n`, `e` delimites par `,` `(` `)` espace ou fin de chaine.


## Tests
Tous les tests sont prefixes par `e11_02_`.

- `e11_02_ld_bc_nn` : 01 34 12 -> 'LD BC,$1234' len 3
- `e11_02_jr_target` : 18 FE a 0x8000 -> 'JR $8000'
- `e11_02_jr_forward` : 20 05 a 0x8000 -> 'JR NZ,$8007'
- `e11_02_ld_a_n` : 3E 7F -> 'LD A,$7F'
- `e11_02_cb_rlc` : CB 00 -> 'RLC B' len 2
- `e11_02_cb_bit_hl` : CB 46 -> 'BIT 0,(HL)'
- `e11_02_djnz` : 10 FC
- `e11_02_jp_nn` : C3 00 80 -> 'JP $8000'
