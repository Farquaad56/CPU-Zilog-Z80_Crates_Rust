# E02-05 - Tests de decode sur les 1280 combinaisons
Epopee: E02 | Type: code | Dependances: E02-04 | Taille estimee: ~70 lignes

## Contexte
Balayage exhaustif de `decode` contre les TSV (aucune ligne ne doit etre oubliee).

## Lire d'abord
- docs/specs/data/{main,cb,ed,ddfd,ddcb}.tsv
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Write only in
- `crates/puce-z80/tests/decode_all.rs`
- `crates/puce-z80/src/lib.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Test d'integration `crates/puce-z80/tests/decode_all.rs` (le crate expose `pub use engine::decode::{decode, Decoded, Table, plan_of}` sous `#[doc(hidden)] pub mod __internal` pour les tests; ajoute ce module dans lib.rs).
Le test lit les 5 TSV (chemin `concat!(env!("CARGO_MANIFEST_DIR"), "/../../docs/specs/data/<nom>.tsv")`) et pour chaque ligne verifie: la somme des durees du plan (min/max) == colonnes t_min/t_max; pour les lignes `prefix`/`-`: `decode` renvoie Prefix/IndexCb/Restart selon la regle de E02-04; sinon `decode` renvoie `Plan` avec `plan.len()` == nombre de jetons de la colonne plan.


## Tests
Tous les tests sont prefixes par `e02_05_`.

- `e02_05_all_rows_main` : 256 lignes main
- `e02_05_all_rows_cb_ed` : 512 lignes cb+ed
- `e02_05_all_rows_ddfd_ddcb` : 512 lignes ddfd+ddcb
- `e02_05_token_counts` : nombre de jetons == colonne plan pour toutes les lignes
