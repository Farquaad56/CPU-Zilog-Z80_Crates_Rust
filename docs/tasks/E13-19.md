# E13-19 - ROMs de timing: execution
Epopee: E13 | Type: code | Dependances: E13-18 | Taille estimee: ~120 lignes

## Contexte
Execute les ROMs de timing retenues en E13-18 sur la machine ZX (avec contention si necessaire).

- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_Z80.md` (a consulter avant toute question)

## Specification
Pour chaque ROM retenue : un test `#[ignore]` dans `crates/puce-z80-cli/tests/timing_roms.rs` (SKIP si absente) avec le critere du doc. Complete la contention de `ZxMachine` (table exacte documentee dans le doc, 48K et 128K si pertinent) et corrige les ecarts de timing du crate (WAIT, INT, HALT, E/S contendues). Chaque ROM acceptee passe; celles marquees `UNAVAILABLE` sont listees comme telles dans le test.


## Tests
Tous les tests sont prefixes par `e13_19_`.

- `e13_19_timing_roms_all` : toutes les ROMs retenues passent
