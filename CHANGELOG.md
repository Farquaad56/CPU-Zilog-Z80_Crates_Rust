# Changelog

All notable changes to this project are documented here.
The format follows Keep a Changelog; versions follow Semantic Versioning
(0.x while the API is not stable).

## [0.1.0] - unreleased

First release of the cycle-accurate Zilog Z80 workspace.

### Added

- `puce-z80`: Z80 CPU core. `no_std`, no allocation, no unsafe code, no dependency.
  - Pin-level engine (`Cpu::tick`, one call per T-state) and instruction-level API
    (`Cpu::step` with a `Bus` trait: ports, INT/NMI, vector, wait states, BUSRQ, `on_tick`).
  - NMOS behaviour of the real silicon: undocumented flags (X/Y), `WZ` (MEMPTR), `Q`
    (SCF/CCF), block instructions, interrupt modes 0/1/2, HALT, RESET, `RETI` observation.
  - Optional features: `std`, `inspect`, `disasm`.
  - Four examples for reuse in other emulators: pin-level host, ZX-like memory contention,
    shared bus (BUSRQ/BUSAK, RESET) and IM 2 with a CTC; multi-CPU and determinism tests;
    `tools/nostd_check.sh` for embedded and WASM targets.
- `puce-z80-machines`: CP/M machine (BDOS functions 2 and 9), ZX Spectrum-like machine for
  the timing ROMs, FUSE and SingleStepTests runners, and the simulation session used by the
  web front end.
- `puce-z80-cli` (`z80`): runs `.com`/`.cim` programs, the test suites (`z80 suite all`),
  disassembly and benchmarks.
- `puce-z80-web` (`z80-web`): local server (HTTP + WebSocket, port 8080 by default) with a
  browser front end (French / English) that only displays the state computed by the crate.

### Behaviour decisions

- The silicon of the NMOS Zilog Z80 is the reference (z80test, SingleStepTests); where FUSE
  disagrees the difference is listed as a known exception.
- After HALT, PC points just past the HALT opcode (as in SingleStepTests).

### Not in this release

- CMOS variant, save states (serde) and a WASM build of the core.
